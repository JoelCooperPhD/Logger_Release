# RSLogger Releases

Download executables for RSLogger — multi-sensor data acquisition software by [Red Scientific](https://redscientific.com).

## Latest Release

Go to the [Releases](https://github.com/JoelCooperPhD/Logger_Release/releases/latest) page to download for your platform:

| Platform | File |
|----------|------|
| **Windows** | `RSLogger-Windows.zip` — extract and run `RSLogger.exe` |
| **macOS** | `RSLogger-macOS.zip` — extract and run `RSLogger.app` |
| **Linux** | `RSLogger-x86_64.AppImage` — `chmod +x` and run directly |

**No installation required.** Just download, extract (if needed), and run.

### macOS Note
On first run, right-click and select "Open" to bypass Gatekeeper, or go to System Preferences > Security & Privacy to allow the app.
